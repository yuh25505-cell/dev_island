# 岛屿机 Island Phone

一部由角色共同生活的原生 AI 手机。角色不只回应用户，也拥有独立日常、朋友、兴趣、记忆、成长与自己的数字生活。

## 产品是什么
岛屿机是 Android 原生 AI-Native 角色生活模拟 App。用户通过虚拟手机与角色生活互动，目标是成熟手机体验，而不是网页套壳聊天机器人。

## 应用规划
- 主屏幕：应用图标、组件、拖动、文件夹、壁纸、快捷入口。
- 聊天：私聊、群聊、联系人、消息类型、动态、角色/NPC、人设与会话设置。
- 外观：壁纸、图标、字体、主题、桌面布局。
- 屿年：角色成长阶段、人生事件、年岁与长期轨迹。
- 相册：每个角色独立相册，聊天截图、生成图与分享。
- 日历：角色自主日程、共享活动与提醒。
- 备忘录：用户笔记/日记、角色私有碎念、共享笔记。
- 天气、时钟：角色地点天气；闹钟、计时器、提醒。
- 设置：AI/API、系统、通知、后台行为、数据储存、备份与导入导出。
- 电话：语音通话体验、记录、收藏、拨打角色。
- 倒数日：纪念日与周年提醒。
- 世界书：角色背景、可排序条目、注入位置、启停。
- 音乐：本地音乐/歌词、网易云接入可行性。
- 相遇：线下长篇、旁白、文风、可选择同步记忆。
- 关联账号：角色与用户双向授权查看手机、消息同步、可撤销。
- 论坛：角色/NPC账号、动态、评论、互动、自主发帖控制。
- 文学城：小说/同人创作、草稿与发布。
- 情侣空间：双向邀请、共同碎念、纪念、共同目标与互动。
- 预设：提示词模块管理、排序、资料读取和记忆流程统一。
- 番外笺：独立 IF 线路，不连主聊天与相遇记忆。
- 美团：虚拟外卖/团购模拟，不产生真实支付订单。
- 栖迟：梦境分支、选项、结局、可选择记忆同步。

## 双向联通
聊天可将消息保存到相册/备忘录、提议日程与提醒、分享论坛帖、同步成长事件；日历与倒数日/情侣空间共享纪念事项；相遇剧情可选择写入共同记忆；角色之间共享关系、群聊、论坛和日程状态；所有 AI App 共享角色/用户资料、世界书与记忆读取服务，但各自玩法独立。所有共享均需明确授权，可撤销，关闭后停止同步。

## 技术
Kotlin + Jetpack Compose + Android SDK；Navigation Compose；Room 保存结构化数据；DataStore 保存设置；文件系统保存媒体；Coroutines/Flow；OkHttp 网络与流式响应；WorkManager 可延续后台工作。AI Provider 适配层与提示词组装分离。Cloudflare 后端起步，服务端验证权限。

## 设计
Apple Liquid Glass 官方资料作为视觉参考，Android 用原生 Compose 实现类似材质，玻璃优先用于导航、浮层、工具栏和交互控件，正文保持可读。模糊可关闭并有设备降级方案。当前主题暂跟随系统；固定日间/夜间将在系统UI任务实现。每个页面与弹窗支持原生返回手势。

启动动画：雨滴落在屏幕中心，水波晕开，显示「请让这座孤岛因你们而拥有属于它的故事」，然后进入主屏。

## 开发规则
开工先读 CLAUDE.md、README、DEVELOPMENT_PLAN 和现有代码。计划按序一次只做一个任务。新增内容支持编辑/删除，功能可关闭/撤销。代码按 UI、数据、网络、AI 职责分层；改动后构建并检查已有功能，更新版本。签名文件与密钥只放 GitHub Secrets，不提交仓库。
