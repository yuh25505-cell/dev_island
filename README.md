# 岛屿机 (Island Phone)

一台装在手机里的「小手机」。你在上面和 AI 角色（char）过日子：聊天、见面、发朋友圈、点外卖、听歌、做梦。
角色像真人一样有自己的生活、朋友、成长，不围着你转，没有 AI 味。

**纯原生 Android App**，不是网页套壳。

---

## 一、这个项目是什么

- 一个模拟真实手机的桌面：图标、文件夹、桌面组件，都能拖动。
- 全局界面是苹果「液态玻璃」风格：透明、清透、丝滑。
- 桌面上有很多 App，每个 App 管一块玩法，而且彼此打通。
- 日间 / 夜间 / 跟随系统，三种模式自由切换。
- 所有页面都支持系统原生的左滑 / 右滑返回上一步。

## 二、为什么必须是纯原生

| 想要的效果 | 原生怎么做到 |
|---|---|
| 长聊天不卡 | 系统原生列表，分页加载 |
| AI 回复时切后台也能收到 | 前台服务 + 后台任务保活 |
| 数据大也稳 | 系统自带数据库 |
| 流式回复不断 | 自己写的原生网络层 |
| 各种手机都能用 | 不依赖系统网页内核 |
| 通知、闹钟、定位、麦克风等 | 直接调用系统功能 |

## 三、页面与 App 一览

### 系统层
- **加载动画**：启动时的开屏动画
- **主屏幕**：多页桌面、拖动图标、建文件夹、桌面组件
- **登录系统**（仅开发者/管理员可见）：审核注册、邀请码、一机一码

| 外观 | 换图标、壁纸、全局字体（上传 ttf） |
| 屿年 | 角色每年的成长线，从学生到工作到升职 |
| 相册 | 每个角色自己的相册簿 |
| 日历 | 角色每天的日程安排 |
| 备忘录 | 你的日记 + 角色的碎碎念 |
| 天气 | 角色所在地的天气温度 |
| 时钟 | 闹钟，角色答应喊你时会真的响 |
| 电话 | 语音通话、通话记录、收藏 |
| 倒数日 | 纪念日提醒 |
| 音乐 | 网易云账号、本地音乐、歌词 |
| 相遇 | 线下见面长剧情，酒馆式叙事，还能「重新经历」过去 |
| 关联账号 | 像 QQ 关联账号，互相能看到对方收到的消息、能登录查手机 |
| 论坛 | 角色和 NPC 发帖、评论 |
| 文学城 | 生成或发布同人文、小说 |

| 美团 | 点外卖、团购（虚拟） |
| 栖迟 | 角色的梦境，文字游戏式选项剧情 |

| App | 作用 |

| 世界书 | 角色背景、活人感提示词，可选注入位置与顺序 |

## 四、App 之间怎么打通（双向）

下面每一条都是**双向**的：A 能给 B 数据，B 也能反过来给 A。

| 连接 | A → B | B → A |
|---|---|---|
| 聊天 ↔ 日历 | 聊天里约好的事自动进角色日程 | 角色今天的日程影响聊天里的状态和回复 |
| 聊天 ↔ 相册 | 聊天里发的图、截图存进角色相册 | 角色从相册挑图发给你 |
| 聊天 ↔ 时钟 | 聊天里说「几点叫我」自动设闹钟 | 闹钟响了，角色在聊天里跟进 |
| 聊天 ↔ 倒数日 | 聊天里提到的纪念日自动记录 | 纪念日当天角色主动发祝福 |
| 聊天 ↔ 天气 | 聊天里提到地点同步到天气 | 角色会聊到当地天气、提醒带伞 |
| 聊天 ↔ 电话 | 聊天里可发起通话 | 通话内容生成摘要回写聊天 |
| 聊天 ↔ 相遇 | 聊天剧情延伸到线下 | 相遇结束后留下聊天记录和记忆 |
| 聊天 ↔ 朋友圈/论坛 | 角色发动态，聊天里可聊到 | 你的评论和点赞影响角色心情 |
| 聊天 ↔ 美团 | 角色可以给你点外卖 | 你点的外卖，角色会在聊天里评论 |
| 聊天 ↔ 音乐 | 一起听歌、分享歌曲 | 你在听什么，角色能知道 |
| 屿年 ↔ 聊天/相遇/日历 | 成长阶段决定角色身份、职业、日程 | 聊天与见面里发生的大事写进屿年 |
| 屿年 ↔ 备忘录 | 成长节点触发碎碎念 | 备忘录里的日记成为成长素材 |
| 日历 ↔ 备忘录 | 日程里发生的事，角色写日记 | 日记里提到的计划进日程 |
| 世界书 ↔ 所有 AI 玩法 | 世界书为每个 App 提供背景 | 玩法中产生的设定可存回世界书 |
| 关联账号 ↔ 聊天/朋友圈/论坛 | 关联后可见对方消息与动态 | 你也能登录对方账号查看 |
| 栖迟 ↔ 屿年/聊天 | 梦境可吸收记忆 | 选择计入记忆后，梦影响角色状态 |
| 情侣空间 ↔ 聊天/倒数日/日历 | 在一起的天数、便利贴进聊天 | 聊天里的大事进空间纪念册 |
| 论坛 ↔ 文学城 | 角色发的帖子可以变成小说灵感 | 小说发布后角色在论坛讨论 |
| 外观 ↔ 全部 | 字体、图标、主题统一下发 | 每个 App 的美化类名都可被主题覆盖 |
| 番外笺 | **刻意不打通**（不进记忆，不连聊天、相遇） | — |

> 打通靠「共用数据」和「事件通知」两种方式，细节写在 CLAUDE.md。

## 五、情侣空间玩法设想

你只想到了便利贴和每天互发「我爱你」，这里补充：

1. **便利贴墙**：互相贴碎碎念，可以置顶、可以回复。
2. **每日打卡**：每天互发「我爱你」，满一年有大奖励。
3. **断了怎么续**：断签后进入「重燃火花」任务，完成 3 个小任务（如：写一封道歉信、一起完成一次约会、回忆一件往事）就从断的天数接着算。
4. **共同心愿清单**：一起写想做的事，完成后打勾，角色也会提议新的。
5. **纪念册**：自动收集聊天里的重要瞬间、照片、通话。
6. **在一起天数 + 里程碑**：100 天、365 天自动弹纪念卡片。
7. **悄悄话信箱**：写给未来的信，指定日期才会打开。
8. **共同日常**：互道早安晚安、今天心情打分、互相猜对方今天过得怎样。
9. **小宠物 / 小花园**：两个人每天照顾，断签就枯萎，重燃火花后复活。
10. **约会计划**：选地点和活动，联动美团、相遇。
11. **吵架和好机制**：闹别扭后系统提示和好任务（可关闭）。
12. **关系纪念日墙**：初次见面、第一次通话等自动记录。

所有可开启的玩法都要能关闭，所有可创建的内容都能编辑和删除。

## 六、分支与发布流程

```
dev（新功能分支）  →  test（测试分支）  →  main（主支）
```

1. 新功能先在 **dev** 做，同时在这里修 bug。
2. 你确认没问题，合并到 **test** 给你测。
3. test 全部没问题，最终合并到 **main**。
4. 每个分支推送后，GitHub Actions 自动打包 APK。
