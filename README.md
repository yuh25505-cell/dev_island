# 岛屿机

一部装在手机里的"AI 小手机"。纯原生 Android App，不是网页套壳。

你和 AI 角色（char）在里面聊天、见面、刷论坛、过日子。角色有自己的生活、朋友和成长，像真人一样，不围着你转，没有 AI 味。

当前版本：`0.1.3`（开发中）

---

## 核心理念

1. **角色是活的**：有日程、有情绪、有朋友、会忙、会晚回，每一年都在成长。
2. **App 之间是通的**：日历里的安排会影响聊天，聊天里说的事也会写进日历，全部双向。
3. **数据在你手里**：聊天、记忆、相册都存在本机；云端只管登录。
4. **像苹果一样好看流畅**：透明清透的液态玻璃界面，丝滑的动效。
5. **纯原生**：长对话不卡、切后台不丢回复、机型兼容更好。

---

## 平台与技术

- 平台：Android 8.0 及以上
- 开发：Kotlin + Jetpack Compose（原生界面）
- 数据：本机数据库，每个账号独立一份
- 登录：Cloudflare 免费额度
- 打包：GitHub Actions 自动打包签名 APK，可直接覆盖安装

详细规则见 `CLAUDE.md`，开发进度见 `DEV_PLAN.md`。

## 聊天 App 详细页面

- **消息页**：会话列表、未读、置顶、免打扰
- **联系人页**：角色、NPC、群聊；可建多个，可编辑可删除
- **朋友圈页**：角色和用户发动态、点赞、评论
- **我页**：用户人设（可多个）、钱包、个人设置
- **私聊页**：文字、图片、表情包、语音、转账、红包、引用、撤回、转发、已读等
- **群聊页**：拉群、群成员、群公告
- **私聊设置页**：背景、记忆方式、角色设置、清空记录、美化主题
- **主题美化**：每个界面部件都有固定名字，用户可以做、导入、导出自己的主题

### 两种记忆
- **总结记忆**：定期把聊天压缩成摘要
- **向量记忆（重点）**：按"意思相近"找回相关往事，再筛选一遍

## 互通表（App 之间双向联动）

所有联动都通过"岛屿事件总线"，每条都有单独开关。

| 联动 | A → B | B → A |
|---|---|---|
| 聊天 ↔ 日历 | 角色在忙 / 睡觉时晚回、不回 | 聊天里约好的事自动写进日历 |
| 聊天 ↔ 时钟 | 闹钟响了，角色发消息 / 打电话 | 你说"八点叫我"自动设闹钟 |
| 聊天 ↔ 天气 | 角色根据天气聊天、提醒带伞 | 聊天里说搬家 / 出差，天气地点随之更新 |
| 聊天 ↔ 备忘录 | 角色把聊天里的事记成碎碎念 | 你分享的日记，角色读后会提起 |
| 聊天 ↔ 相册 | 角色截图聊天存相册，发照片给你 | 你发的图片可存入角色相册 |
| 聊天 ↔ 屿年 | 角色当前身份、阶段影响说话方式 | 聊天里的大事成为屿年里程碑 |
| 聊天 ↔ 相遇 | 线下剧情总结进入聊天记忆 | 聊天记忆成为线下见面的前情 |
| 聊天 ↔ 电话 | 通话文字记录出现在聊天里 | 聊天内容成为通话的话题 |
| 聊天 ↔ 倒数日 | 倒数日当天角色主动祝福 | 聊天里提到的纪念日自动加入倒数日 |
| 聊天 ↔ 音乐 | 角色分享歌曲、一起听 | 你在听的歌，角色能看到并聊起 |
| 聊天 ↔ 美团 | 角色给你点外卖送来 | 你点的外卖，角色知道并评论 |
| 聊天 ↔ 朋友圈 / 论坛 | 角色发的动态 / 帖子 | 你的评论让角色回复、记住 |
| 聊天 ↔ 关联账号 | 关联角色能看到你收到的消息 | 你能看到关联角色收到的消息 |
| 聊天 ↔ 情侣空间 | 空间里的互动会在聊天里提起 | 聊天氛围影响空间里的反应 |
| 聊天 ↔ 栖迟 | 角色会说"我昨晚梦到你了" | 聊天内容成为梦的素材 |
| 日历 ↔ 天气 | 下雨改行程 | 行程地点决定天气地点 |
| 日历 ↔ 屿年 | 当前阶段决定日程类型（上学 / 上班） | 日程里的重要事件积累成成长记录 |
| 日历 ↔ 美团 | 午饭时间自动点外卖 | 点过的外卖出现在当天日程 |
| 日历 ↔ 备忘录 | 待办事项出现在日历 | 日历事件可生成备忘 |
| 日历 ↔ 倒数日 | 纪念日显示在日历上 | 日历里标记的日子可变成倒数日 |
| 论坛 ↔ 文学城 | 角色在论坛推荐小说 | 小说引发论坛讨论 |
| 相遇 ↔ 屿年 | 剧情推进角色成长 | 角色新阶段改变见面剧情 |
| 相遇 ↔ 相册 | 见面拍的照片存入相册 | 相册照片可作为见面话题 |
| 钱包（共用） | 聊天转账、红包、美团付款、情侣空间奖励 | 统一余额与账单，互相可查 |
| 世界书 / 预设 | 所有 App 都会读取 | 所有 App 的玩法可调整提示词 |

> 番外笺是唯一"单向"的：只读取角色资料和世界书，不写回任何地方，保证平行世界不串味。

## 情侣空间玩法构思

**已有想法**
- 便利贴碎碎念
- 每天互发"我爱你"，满一年有大奖励；中断后需要"重燃火花"才能续上

**建议新增**
1. **心情打卡**：每天互相报心情、天气，角色会据此关心。
2. **每日一问**：每天一道问题，两边都答完才能看到对方答案。
3. **悄悄话信箱**：写给未来的信，约定日期才能打开。
4. **一百件小事**：共同的心愿清单，角色会主动提议去完成。
5. **共养小岛**：一起养植物 / 小宠物，每天互动才会成长。
6. **共同歌单**：和音乐 App 联动，一起收藏歌曲。
7. **共同相册**：一起存照片和聊天截图，自动生成"那一天"回忆。
8. **陪伴时长**：一起专注、一起入睡，累计陪伴小时数。
9. **默契挑战**：互相猜对方的答案，答对得分。
10. **纪念日自动生成**：第 100 天、一周年等自动出现，到时有惊喜。

**重燃火花（断签后怎么续）**
- 断签后进入"熄火"状态，不清零，只是暂停。
- 完成其中一项即可续上：写一封信给对方、一次通话、一场相遇剧情、或用"补签卡"补满缺的天数。
- 补签卡通过完成每日一问、心愿清单等获得。
- 续上后从断的那天接着算，之前的天数全部保留。

## 需要提前知道的风险

- **网易云音乐**没有官方开放接口，接入要用第三方方案，可能随时失效，放到后期单独评估。
- **国产手机后台限制**很严，保活需要引导用户在系统里手动放行。
- **向量记忆和重排**依赖你配置的模型接口，调用会产生费用。
